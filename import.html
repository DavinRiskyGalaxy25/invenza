Import Inventory Records

Upload existing spreadsheets or JSON datasets to batch-populate your catalog

Import products seamlessly from Excel (.xlsx/.xls), CSV (.csv), or JSON (.json) files. All parsed products are securely saved to your active workspace account.

File Header Schema & Guidelines

Ensure the first header row of your spreadsheet matches the column structure below:

Code | Product Name | Category | Price | Stock | Unit | Supplier | Brand | Condition | Location | Notes | Image URL
  • Product Name and Category are required fields.
  • Other columns are optional and can be left blank if not available.
  • If Code is empty, item codes are automatically generated based on the category.
  • Valid Condition values: Good (or New/Good), Fair (or Fair), Damaged (or Damaged).
  • Image URL is optional (must be a valid https://... image link).
