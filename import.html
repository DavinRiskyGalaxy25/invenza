Import Data Barang

Import data barang dari file Excel (.xlsx/.xls), CSV (.csv), atau JSON (.json). Semua data yang berhasil diimport akan otomatis tersimpan ke akun Anda yang sedang login — data pada file (termasuk kolom user_id jika ada) tidak pernah digunakan untuk menentukan pemilik data; pemilik selalu ditentukan dari sesi login Anda saat ini.

Format Kolom File Import

Gunakan nama kolom berikut pada baris pertama file Excel/CSV Anda:

Kode | Nama Barang | Kategori | Harga | Stok | Satuan | Supplier | Publisher | Kondisi | Lokasi | Catatan | Gambar
  • Nama Barang dan Kategori wajib diisi.
  • Kolom lainnya boleh dikosongkan jika tidak diperlukan.
  • Jika Kode dikosongkan, kode barang dibuat otomatis berdasarkan Kategori.
  • Nilai Kondisi yang valid: Bagus, Rusak Ringan, Rusak.
  • Gambar opsional, isi dengan URL gambar (mis. https://...). Boleh dikosongkan; jika URL tidak valid, barang tetap diimport tanpa gambar.
  • Untuk file JSON, gunakan nama properti image_url atau gambar_url.
Lihat contoh baris data
GPU-001 | RTX 3060 | GPU | 4500000 | 5 | Unit | ASUS | NVIDIA | Bagus | Rak A1 | Barang baru | https://example.com/rtx3060.jpg

Format didukung: .xlsx, .xls, .csv, .json
